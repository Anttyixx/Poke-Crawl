# Starter Selection

Status: 🟡 basic pass — see [00-index.md](00-index.md)

## Decided

- The classic fire/water/grass trio — 3 starters, one of each type.
- This becomes the player's first team member and occupies one of their 6 team slots (see [05-team-management.md](05-team-management.md)).
- The pool doesn't expand over time — since there's no meta-progression ([09-roguelite-run-structure.md](09-roguelite-run-structure.md)), every run offers the same 3 starters from a clean slate.
