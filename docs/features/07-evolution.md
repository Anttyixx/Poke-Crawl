# Evolution

Status: 🟡 basic pass — see [00-index.md](00-index.md)

## Decided

- Both **level-based** and **item-based** evolution triggers are in scope — some Pokémon evolve by leveling up, others need a specific evolution item found on the map (see [06-items.md](06-items.md)).
- Evolutions don't persist between runs — no meta-progression means every run starts from unevolved starters again (see [09-roguelite-run-structure.md](09-roguelite-run-structure.md)).

## Open questions for the detail pass

- Is evolution automatic the moment conditions are met, or does the player choose when to trigger it?
- Which specific Pokémon in the roster use level triggers vs. item triggers?
