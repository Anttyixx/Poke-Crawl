# Move cleanup (0.4.0)

Goal: fewer moves that do almost the same thing, so players have less to learn. Mega signatures were left alone.
Before: 225 moves (111 shared signatures, 26 unique signatures, 88 tutor). After: 201 (103 shared, 25 unique, 73 tutor) plus 1 new move.

## Merged (old → the move that replaces it)

| Removed | Now uses | Why |
|---|---|---|
| Scratch | Tackle | Identical ★1 Normal hit |
| Peck | Gust | Identical ★1 Flying hit |
| Pursuit | Bite | Identical ★1 Dark hit (Bite is now also a signature) |
| Fury Attack | Double Hit | Both Normal multi-hit ★2 attacks |
| Tri Attack, Hyper Fang | Body Slam | Plain ★2 Normal hits of nearly the same power |
| Defense Curl, Iron Defense | Harden | All "the next hits deal less damage"; Harden is now 3 hits at 40% less, teachable to every Pokémon |
| Charge | Focus Energy | Same effect (next hit +50%) |
| Howl | Helping Hand | Both raise teammates' Attack |
| Feather Dance | Growl | Both lower the enemy row's Attack; Growl now lowers it 15% and Flying Pokémon can learn it |
| Roost, Moonlight | Recover (new) | Same self-heal (40%), now one move for Flying and Fairy |
| Dragon Dance | Calm Mind | Same effect (+20% Attack and Speed); Dragons can now be taught Calm Mind |
| Growth | Swords Dance | Both raise the user's Attack; Swords Dance is now ★2, +40%, for Grass Pokémon too |
| Aromatherapy | Lunar Blessing | Both heal the whole team; Grass Pokémon can now be taught Lunar Blessing |
| Light Screen | Reflect | Both cut damage to the front row |
| Mist, Refresh | Safeguard | All protect against stat drops or clear damage over time; Safeguard is now ★2 for Normal, Ice and Fairy |
| Thunder Wave | Nuzzle | Both slow one target |
| Mud Shot | Bulldoze | Both slow targets; Bulldoze is now ★1 |
| Retaliate | Facade | Both double power in a bad spot |

## Removed (no Pokémon used them)

Dynamic Punch, Barrier, Crabhammer.

## Made unique signatures

Headbutt (Dunsparce line) and Icicle Spear (one line): shared signatures only one line had.

## Rules now

- A tutor move can also be a line's signature (Bite, Harden, Calm Mind, Lunar Blessing). The signature slot takes any signature of the Pokémon's line; the taught slot takes any tutor move.
